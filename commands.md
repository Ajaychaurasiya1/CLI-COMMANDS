# CLI COMMANDS

## 1. pwd : print working directory, it will let us know where we are.

## 2. ls : listing files, this commands is used to list down the existing files name.

## 3. ls -a : listing files, this commands help us to find out all the files even the hidden ones which were not shown by using the command "ls".

## 4. ls -l : listing files, this one is used for listing the files with more information like file and directory permissions, creation dates etc.

## 5. ls -la : listing files, it will list down all the files even the hidden one with more information.

## 6. cd . : change directory, This command will make you stay in the same directory.

## 7. cd .. : change directory, this commands will move one step back, or move back to the parent directory.

## 8. cd / : change directory, this commands will move to the absolute root of the file system.'

## 9. cd ~ : change directory, it will move to home of the system

## 10. clear : It is used to clear the terminal

## 11. mkdir : This is used to create the new directory

## 12. touch : this is used to create the new file

## 13. nano and vim : these two are the text editor, and with the help of these two we can write content in the selected file

## 14. cat : To see what's in the file

## 15. less : if the file is too long and we want to have the page down.

## 16. mv : this is used to move or rename the files

## 17. cp : This is used to copy the content of the file from one to another.

## 18. rm : It is used to delete the file only, empty one.

## 19. rm -r : it is used to delete the file and directory even if the file is not the empty.

## 20. rmdir : Used to delete the directory.

## 21. which : This one is used to look for the runnable program only in the current path and it stops when it encounter the first one, and shows the exactly what to execute

## 22. whereis : looks for the everything related to the program in the system folder and then it shows the runnable program, help manual and its source files all of them at once.

## 23. tree : To see the folder and files in visual tree layout

## 24. history : to see the list of the previous commands

## 25. sudo : superuser do, it allow the user to execute the commands with root level privilege without login as root user

## 26. ifconfig : it gives the network information

## 27. iwconfig : it gives the information about the wireless extension

## 28. ping : it is use to send package to the domain or address and it will tell if we are getting any response from there or not.

## 29. uname -a it provides the summary of the system.

## 30. blkid : shows the harddrive

## 31. top : show process, how much memory and cpu it is taking

## 32. df : it show the available and unavailable disk space

## 33. lsusb : shows the list of devices like usb, hub etc.

## 34. lspci : show pic list, all the driver status status which are present

## 35. sudo shutdown : used to shutdown the system.

## 36. sudo shutdown -r : to restart the system.

## 37. chmod : change the permission on the object.

## 38. chown : it is use to change the ownership of the file which is owned by different user.

## 39. netstat : it is used to show the detailed information about network connectivity and network activity

## 40. nmcli device : it is use to see the active wi-fi status

## 41. curl : it is used to test the endpoint or send the request to the url.

## 42. echo : whatever written it shows as the output.

## 43. ps $$ : it shows the snapshot of the process running the current process id

## 44. echo $SHELL : it show the default login system;

## 45. xdg-open : it is used to open the anything including the files and some url

## 46. pipe (|) : it is use to used as output of one command redirect it to the input of the another command .

## 47. xargs : it is used to convert the standard input into command line argument

## 48. grep : it is used to search for the particular string or keywords from the file and print that line matching a pattern

## 49. wget : it is used to download files from the internet or retrieve resource from the web server

## 50. man : manual, it shows the fundamental internal document for the commands

## 51. tr : it is used for translating or deleting the characters

## 52. apt : it is used to update package manager

## 53. sort : it is used to sort the lines in the files

## 54. tar : archive multiple files and directory in one files

## 55. kill : it is use to terminate the process with process id
